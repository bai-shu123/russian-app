Large Russian-Chinese dictionary data
====================================

Generated from the FreeDict Chinese-Russian dictionary, edition 2025.11.23.

Source:
https://download.freedict.org/dictionaries/zho-rus/2025.11.23/

The FreeDict package states that the dictionary was generated by WikDict,
with base data from Wiktionary via DBnary.

This app stores a derived Russian-to-Chinese JSON index generated from the
source Chinese-to-Russian TEI dictionary for offline browser lookup.
